# administracao.sobei.org.br

Painel Administrativo da SOBEI (Sociedade Beneficente Equilíbrio de Interlagos).

## Módulos
- **Denúncias:** Apuração, histórico de estados, registro de medidas adotadas e conclusão/arquivamento.
- **Banco de Talentos:** Consulta de currículos recebidos pelo Trabalhe Conosco.
- **Vagas:** Criação, edição e encerramento de processos seletivos.
- **Mensagens (Fale Conosco):** Gestão de contatos enviados para as unidades.
- **Congresso SOBEI:** Visualização e gerenciamento de participantes inscritos.
- **Usuários:** Controle de acesso e administradores do sistema.
- **Estatísticas:** Painel de indicadores e métricas operacionais.

## Execução Local
```bash
npm install
npm run dev
```
Porta padrão: `http://localhost:3002` (configurada para evitar conflito com os portais públicos).
